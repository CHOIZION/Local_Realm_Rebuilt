# {{name}}

This folder is a realm made with Local Realm. It is yours, and it stays readable without the application.

- `world.json` - realm identity and metadata.
- `world.db` - SQLite database holding entities, types, properties, relationships and the search index.
- `content/` - Markdown articles, one file per entity, with YAML front matter.
- `media/` - images, audio, video and other attachments, stored as ordinary files.
- `backups/` - rolling snapshots of the whole realm.
- `exports/` - anything you export.

Copy this folder to another machine, open it in Local Realm, and carry on. No account required.
