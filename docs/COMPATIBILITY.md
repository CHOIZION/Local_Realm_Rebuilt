# 호환성과 검증 범위

이 문서는 재구현의 완료 여부를 명령 개수만으로 판단하지 않기 위한 기록입니다.

## 구현 및 자동 검증

- 원본 화면의 183개 IPC 명령을 새 Rust 핸들러에 등록합니다. 명령 누락 검사를 빌드 테스트에 포함합니다.
- Tauri MockRuntime으로 실제 IPC 인자 변환과 응답을 검사합니다. 분류 조회, 엔티티 생성, 문서 저장·읽기, 바이너리 지도 저장·읽기를 운영체제 창 없이 검증합니다.
- 내장 샘플을 원본 설치 폴더 없이 생성하고 DB 무결성, 지도 픽셀 및 지도·연표 등이 포함된 공유 HTML 출력을 검사합니다.
- 세계관 생성, 기본 분류와 속성, 문서 저장·검색·역참조·수정 이력, 삭제·복원·재실행을 검증합니다.
- DB 커밋과 파일 저장 사이의 중단을 재현하고 다시 열 때의 복구를 검증합니다.
- 원본 샘플의 날짜 수치와 양수·0·음수 연도 및 윤년 계산을 검증합니다.
- 지도 픽셀을 저장했다가 다시 읽어 비교합니다. 지도 삭제·복원 후 PNG와 사건의 핀 연결을 검증합니다.
- 원고 삭제·복원 후 장, 본문 파일, 외래 키 무결성을 검증합니다.
- 순환 관계 그래프와 숫자 속성의 표 필터·정렬·합계를 검증합니다.
- 스냅샷을 만든 뒤 원본을 수정해도 복원본이 스냅샷 시점을 유지하는지 확인합니다. 압축 파일 경로 탈출과 기존 폴더 덮어쓰기를 거부합니다.
- JSON 왕복, Markdown 가져오기, 가져온 엔티티 링크와 숫자 속성을 검증합니다.
- JSON 첨부 파일 연결, 반복 가져오기의 미디어 중복 방지, 순환 분류의 가져오기 취소 및 Markdown 내보내기 링크를 검사합니다.
- 한글 원고를 PDF·DOCX·EPUB·Markdown으로 출력합니다. PDF 텍스트 추출, 페이지 수, DOCX 재읽기, EPUB XML 구조를 검사합니다.

## 원본과의 차이 및 아직 검증되지 않은 부분

- 원본 Svelte/TypeScript 개발 소스는 없어 복구한 배포용 화면을 사용합니다. 프런트엔드의 원래 의존성 잠금 파일도 없습니다.
- 지형 생성과 침식은 새 알고리즘입니다. 같은 시드가 원본과 같은 지형을 만들지는 않습니다. 모든 세계 모양·바람·기후 설정이 원본 생성 규칙과 동일하다는 검증은 없습니다.
- 원본 앱이 남긴 휴지통 payload와 외부 JSON 번들의 모든 변형에 대한 호환성은 확보하지 못했습니다. 새 앱이 만든 휴지통과 JSON 왕복은 테스트합니다.
- PDF/DOCX의 조판, Word 가져오기의 복잡한 서식·표·내장 이미지, EPUB의 모든 출판 옵션은 원본과 동일하게 재현됐다고 보장하지 않습니다. PDF 글리프를 찾지 못하면 누락시키지 않고 오류를 반환합니다.
- 공유 HTML은 별도의 정적 표현입니다. 앱의 3D 지도와 관계도 편집 화면 자체를 내보내는 것은 아닙니다.
- 일반적인 데이터 처리 자동 테스트를 수행했으며, 전체 Windows GUI의 모든 편집·드래그·대화상자 동작을 원본과 나란히 비교하는 검증은 끝나지 않았습니다.
- 원본 대비 전체 앱 실행 시간·메모리·프레임 속도 개선율은 측정하지 않았습니다.

따라서 이 버전은 **재구현 검증판**이며, 원본과 완전히 동등한 정식 대체판이라는 표시는 하지 않습니다.
