# Local Realm Rebuilt 1.9.0-rebuilt.1

Rust/Tauri 재구현 검증판입니다. 원본 실행 파일이 없어도 동작하도록 빌드합니다.

1. ZIP 전체를 새 폴더에 풉니다.
2. `local-realm-rebuilt.exe`를 실행합니다.
3. 새 세계관 또는 포함된 샘플을 만들어 사용합니다. 기존 세계관은 복사본으로 먼저 확인할 수 있습니다.

`WebView2Loader.dll`, `brushes`, 고정 WebView2 런타임 폴더가 들어 있다면 실행 파일 옆에 그대로 두세요. 고정 런타임이 없는 경우 설치된 WebView2가 필요합니다.

이 실행 파일은 코드 서명되지 않았습니다. Windows에서 게시자를 확인할 수 없다고 표시할 수 있습니다. 함께 제공된 SHA256SUMS.txt로 파일을 확인할 수 있습니다.

전체 원본 동작에 대한 동등성 검증은 끝나지 않았습니다. 알려진 차이와 테스트 범위는 같은 폴더의 COMPATIBILITY.md에 있습니다. 기존 최적화판이나 원본 실행 파일은 이 릴리즈에 포함하지 않습니다.
